# 지곡동 · Google Flow 제작 파일

25초 도입부 시범 제작용 파일입니다.

- [전체 파일 ZIP](downloads/jigok_files.zip)
- [Flow에 업로드할 원본 이미지](downloads/jigok_flow_image.png)
- [25초 무음 시안 영상](downloads/jigok_intro.mp4)
- [장면별 Flow 프롬프트와 내레이션](downloads/flow_prompts.md)

GitHub에서 파일을 연 뒤 **Download raw file** 버튼(아래쪽 화살표 아이콘)을 사용해 저장하세요. 비공개 저장소라면 접근 권한이 있는 GitHub 계정으로 로그인해야 합니다.

Flow에서는 PNG 이미지를 첨부하고, 프롬프트 문서의 장면 A부터 생성합니다. MP4는 생성 정지 이미지에 느린 확대와 자막을 적용한 무음 시안이며, Google Flow에서 생성한 동영상이 아닙니다. 이미지는 실제 지곡동의 역사적 풍경이나 지형을 복원한 것이 아닌 상상 이미지입니다.

이 브랜치는 파일 전달용입니다. 기존 main 브랜치를 변경하지 않습니다.
